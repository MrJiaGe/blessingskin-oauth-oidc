# 多语言

> 来源：https://bs-plugin.netlify.app/guide/i18n.html

先讨论 PHP 端的多语言，关于 JavaScript 的前端多语言放在最后。

所有语言文件按语种放在插件目录下的 `lang` 目录内。Blessing Skin Server 支持英文（`en`）和简体中文（`zh_CN`）。所有语言文件均为 YAML 文件，以 `.yml` 后缀保存。

## 目录结构

`lang` 目录可根据需要继续建立更深层次的目录。访问时用小数点 `.` 表示目录结构：

```
/lang
    /en
        /user
            /baby
                /info.yml
    /zh_CN
        /user
            /baby
                /info.yml
```

访问 `info.yml` 时：`user.baby.info`。

## 语言文件结构

键-值对形式记录文本：

```yaml
title: 欢迎访问

content:
    header: 您好，:name
    footer: '某些时候您可以用引号包住语言值'
    body: |
        这是
        多行
        文本
```

### 多级结构

可层级分类，访问仍用小数点 `.`。如访问 `content.footer`：`user.baby.info.content.footer`。

> 实际应用中必须加上命名空间。

### 占位符

英文冒号 `:` 加变量名即可成为占位符。

### 多行文本

使用 `|` 表示多行文本的开头。

## 调用语言文件

通过 `trans` 函数使用语言文件（Twig 示例）：

```twig
{{ trans('user.baby.info.content.footer') }}
```

占位符需传递数据：

```twig
{{ trans('user.baby.info.content.header', {name: username}) }}
```

## 前端的多语言（v3）

文件名必须为 `locale.js`，位于各语种目录：

```
/lang
    /en/locale.js
    /zh_CN/locale.js
```

以 JavaScript 对象形式保存：

```js
$.locales['zh_CN'].hello = {
  title: '欢迎访问',
  content: {
    header: '您好，:name',
    footer: '没有了',
    body: '这是' + '多行' + '文本'
  }
}
```

`hello` 类似命名空间，起到区分作用。占位符用法同上。

使用语言文件也用 `trans` 函数，占位符传 JavaScript 对象：

```js
trans('hello.content.header', { name: userName })
```

不要忘了 [注册多语言](#)。

## 前端的多语言（v4）

与 v3 类似，但语言文件不需要声明语种：

```js
// $.locales['zh_CN'].hello = {
blessing.i18n.hello = {
    title: '欢迎访问',
    content: {
      header: '您好，:name',
      footer: '没有了',
      body: '这是' + '多行' + '文本'
    }
}
```

`trans` 用法相同。

## 前端的多语言（v5）

**v5 不再需要编写 JavaScript 代码**。

直接在 `lang/{locale}/front-end.yml` 下编写文本即可（像其它 l10n 文件），**不需要手动注册**。

`front-end.yml` 下的文本条目会保存在以插件 `name` 为键的对象下。

如插件 `name` 为 `test`，`front-end.yml`：

```yaml
name: kumiko
```

调用：

```js
trans('test.name')  // ==> kumiko
```
