## 项目全量解析
- 应用户要求对 blessingskin-oauth-oidc 插件做了完整代码解析（AI Coding 场景）。
- 插件定位：BlessingSkin 5.x/6.x 的 OIDC 第三方登录插件，v1.2.1，MIT，作者 MrJiaGe。
- 技术栈：PHP 7.4+ / Laravel Socialite + Eloquent + Cache + Session / Twig 模板 / YAML i18n。
- 6 个核心组件：OIDCProvider(Socialite驱动)、OIDCExtendSocialite(注册)、OIDCAuthController(回调主入口)、OIDCLinkController(账号关联)、OIDCSession(Session+Cache双写)、OIDCUserBinding(绑定模型)。
- 数据表 oidc_user_bindings：uid ↔ oidc_sub + oidc_issuer，UNIQUE(sub,issuer)。
- 关键设计：基于 sub 绑定而非邮箱；Session+Cache 双写绕过 Session regenerate；OIDC_LINK_ENABLED 开关。
- 已产出两张可视化图：架构总览 + 登录绑定决策流程图。

## 两个部署 Bug 修复 + 死代码清理
- Bug1 侧边栏菜单不高亮：根因 `SideMenuComposer::transform()` 用 `$request->is($item['link'])` 匹配，link 必须无前导斜杠。已将 bootstrap.php 的 `'link' => '/admin/oidc'` 改为 `'admin/oidc'`（与 BS 原生菜单如 'admin/users' 一致）。
- Bug2 编辑/删除按钮无反应：根因 `{% block before_foot %}` 的 IIFE 在 jQuery/Bootstrap 加载前执行，`jQuery().modal('show')` 静默失败。已改用 Bootstrap 声明式触发 `data-toggle="modal" data-target="#editModal"/#deleteModal`（document 级事件委托，不受加载时序影响），成功后用 `window.location.reload()` 代替程序化 `modal('hide')`。
- 死代码清理：admin-bindings.twig 第 337 行原本 `editBtn.textContent = ... ? undefined : undefined;`（两个三元分支都是 undefined，按钮文字会变 undefined）。已改为 `editBtn.textContent = L.confirm;`，并在 L 对象补充 `confirm` 键（读 admin_confirm），同时把保存失败重置（原按 field 显示 edit_sub/edit_issuer）统一改为 `L.confirm`，与初始/失败状态一致。admin_confirm 键中英文语言包均已存在。
- 用户调试偏好：调试时多次要求「先不要编写代码，查找原因」，需先分析根因再动手；坚持不改 BS 源码、只调用/模仿原生功能。
